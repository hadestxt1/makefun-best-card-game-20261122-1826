Ember Court: an original card duel in plain static files. You face Marlowe, Warden of the Tide, across a table of four court suits — Ember, Gale, Stone and Tide — each with the advantage over one other; every round both sides lay one card, the higher power wins and deals the difference in damage, and a Crown (7) win restores life. First to 0 life loses.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click a card or press 1–5 to play it, Space to start, R to restart. The screenshots in screenshots/ are staged scenes of the real game (`?shot=title|play|win|loss`).
